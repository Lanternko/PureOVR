# 裁決（rulings）

使用者對球員評價、驗收方式、流程的裁定，以及籃球規則與硬規則。卡片、模擬與驗收不得違反。讀寫規則見 [README.md](README.md)。

2026-10-30 依使用者要求整併：同主題的裁決合成一條（保留該主題最常被引用的 ID），過時的刪掉。舊 ID 去哪裡，見檔尾「舊 ID 對照」；其他檔引用舊 ID 時查那張表。

欄位（固定）：
- **ID**：`R-001` 起，只追加。新裁決若和既有主題相同，改寫該主題條目，並在「合併」欄記上新 ID。
- **日期**：最初裁定日（最後修訂日）。
- **裁決**：一句話。
- **細節**：適用範圍、例外、怎麼做。
- **狀態**：`有效`｜`暫定`｜`已廢止`。改狀態時括號註明日期與原因。
- **合併**：併進這條的舊 ID。
- **相關**：其他 ID。
- **來源**：誰說的、對話日期或 commit。

範例：

```
### R-999
- 日期：2026-10-27
- 裁決：OVR 可以超過 99，也可以低於 40。
- 細節：驗收不用固定範圍。
- 狀態：有效
- 相關：L-013
- 來源：使用者 2026-10-27
```

## OVR 定義

### R-025
- 日期：2026-10-28（2026-10-30 整併）
- 裁決：OVR＝「把這名球員和四個聯盟平均隊友放上場，每場能帶來多少比賽影響力」，含上場時間，分鐘權重要邊際遞減。卡片與賽中都照這個定義。
- 細節：
  - 上場時間與得分量增加都算影響力增加；賽中 OVR 也不是只看命中率等比率。不要用「OVR 只看能力」「得分量已在 creation 裡」為賽中結果辯護（Ty Jerome 反例）。
  - 基準用替補水準：g = (pred − r_repl) × W(mpg)，r_repl 為 MIN≥500 池 pred 的 PR10。選替補水準是定義裁定，不是證據（對平均基準樣本外差不顯著）。
  - 分鐘權重用飽和曲線 W(m) = (1 − e^(−m/15)) / (1 − e^(−36/15))，每場 36 分鐘 = 1；15→20 分鐘差很多，30→35 差不多。曲線是價值定義，選定前只看形狀，不用量尺挑（量尺本身對分鐘線性）。
  - 待辦：「接戰場分鐘」（用比分接近時的上場時間取代整季 MPG）。2025-26 MPG≥30 的人，終場差 ≤5 時平均多打 2.1 分鐘。研究時不能假設每個人的每 36 影響力都能延伸到 40 分鐘以上。
- 狀態：有效
- 合併：R-026、R-027、R-028、R-043、R-047
- 相關：R-012、R-033、F-029、E-064、E-084、E-089、L-026、L-035
- 來源：使用者 2026-10-28、2026-10-29
